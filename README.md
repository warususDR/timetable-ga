# Timetable-GA

## Overview
Timetable-GA is a C# project that implements a genetic algorithm to automatically generate and optimize scheduling timetables. This repository serves as a computational approach to resolving complex scheduling conflicts, efficiently allocating resources, and demonstrating the practical application of evolutionary algorithms to constraint satisfaction problems.

## Technologies Used
* **Language:** C#
* **Framework:** .NET

## Key Concepts Covered
* **Genetic Algorithms:** Implementation of core evolutionary mechanics, including selection, crossover, and mutation operations.
* **Constraint Satisfaction:** Algorithmic resolution of hard and soft scheduling constraints to prevent overlaps and optimize availability.
* **Fitness Evaluation:** Design and application of fitness functions to continuously score and improve the generated timetables over multiple generations.
* **Resource Allocation:** Automated management of scheduling variables such as time slots, designated locations, and assigned personnel.
